# PICARD2 Onboarding Portal

This is the active onboarding portal for the second-generation PICARD implementation. Open `index.html` directly or serve this directory with any static file server.

The portal is based on the migration assessment in `../picard_new_generation/docs/` and records:

- the current, statically assessed state of PICARD2;
- the PICARD1 capabilities that still require retain/redesign/retire decisions; and
- the implementation sequence from migration stabilization to hyperparameter sweeps.

The superseded PICARD1 portal is preserved at [`archive/picard1/index.html`](archive/picard1/index.html). It is historical evidence, not current setup or architecture guidance.

## Maintenance

Update this portal whenever a capability changes status, a migration-scope decision is made, or a phase exit criterion is met. Keep the detailed evidence and work logs in `../picard_new_generation/docs/`; keep this portal concise and team-facing.
