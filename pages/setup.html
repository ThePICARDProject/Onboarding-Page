Getting started with PICARD

PICARD2 is not currently available on the project machineBeginning-of-semester setup and bug fixes are required before the application will be running and accessible. The design team will need to hang tight while that work is completed; we will let you know when PICARD2 is ready to use. In the meantime, browse the research documentation and background history, review PICARD2’s current design, and learn about the planned experiment model.

The PICARD project uses a remote WVU machine. Reaching it requires two SSH connections: first to WVU’s gateway, then from that gateway to the PICARD host.

Your macOS or WSL terminal→WVU SSH gateway→PICARD machine
Two approvals are requiredGateway access and a PICARD machine account are separate. WVU must grant gateway access, and Dr. Devine or another PICARD team member must create your account on the PICARD machine.

These instructions use a terminal in macOS or Windows Subsystem for Linux (WSL). Replace every placeholder in angle brackets with your own account information before running a command.

1. Request WVU gateway access

  1. Open the WVU SSH Gateway access form ↗.
  2. Use 157.182.194.132 as the destination IP address when completing the request.
  3. Wait until WVU confirms that your access has been granted.
  4. From your macOS or WSL terminal, verify the gateway connection with your school username:
ssh <your-school-username>@ssh.wvu.edu

A successful login leaves you at a shell prompt on the WVU gateway. Keep this SSH session open for the next step.

2. Connect from the gateway to PICARD

  1. Ask Dr. Devine or another PICARD team member to create your account on the PICARD machine if you do not already have one.
  2. From the gateway session you opened above, connect to the PICARD host:
ssh <your-picard-username>@picard.csee.wvu.edu
Success checkIf the command logs you in and shows a shell prompt on the PICARD machine, your required access is set up. You can stop here or configure the optional shortcut below.

3. Optional: configure an SSH shortcut

An SSH configuration lets your computer use the WVU gateway as a jump host automatically.

  1. On your computer, go to ~/.ssh/. Create the file config if it does not exist, then open it in an editor. For example:
cd ~/.ssh
vim config

If Vim is unfamiliar, see this basic Vim guide ↗.

  1. Add the following configuration. Replace both username placeholders; if your PICARD username differs from your school username, use the correct value in each host block.
Host gateway
    HostName ssh.wvu.edu
    Port 22
    User <your-school-username>
    IdentityFile ~/.ssh/id_rsa

Host picard
    HostName picard.csee.wvu.edu
    User <your-picard-username>
    Port 22
    IdentityFile ~/.ssh/id_rsa
    ProxyJump gateway
  1. Check the contents of ~/.ssh/. If id_rsa does not exist, generate the key pair:
ssh-keygen -t rsa
  1. Copy your public key to PICARD. Enter your password or passwords when prompted; the same password may be requested several times.
ssh-copy-id picard
  1. Use the new host shortcut to connect:
ssh picard

You may still enter your gateway password once. SSH then jumps through the gateway and logs in to PICARD using your identity.
